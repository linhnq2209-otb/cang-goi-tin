# Cảng Gói Tin

Ứng dụng ôn tập Tin học dạng trò chơi cho học sinh THPT Hữu Nghị 80 (sách Kết nối tri thức).

- Mở trực tiếp: bật GitHub Pages (Settings → Pages → Branch `main`, thư mục `/root`), trang chạy ở `https://<tài khoản>.github.io/cang-goi-tin/`.
- Kho này để **Public** và **không chứa dữ liệu học sinh**. Dữ liệu nằm ở kho riêng tư `cang-goi-tin-data`.
- Hiện tiến độ lưu trên trình duyệt từng máy. Đồng bộ qua kho dữ liệu sẽ bật khi có trạm Apps Script và mã đăng nhập Google.
